FAQ / ACCORDION
How does the shared library work?
Components share structure and behaviour. Each website supplies its own content, theme and integrations.
Can websites have different colours?
Yes. The component geometry stays consistent while brand-specific variables change the palette.
Does this connect to live systems?
No. The showcase is an isolated visual reference, not a booking or ecommerce application.
